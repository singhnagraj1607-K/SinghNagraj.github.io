HRMS & Payroll Module Case 01

Automated Payroll Logic & Biometric HRMS Architecture

01. Problem

ESSL biometric punch logs didn't align with rotating cafe week-off schedules and cross-midnight shifts, causing 3-day payroll delays and recurring salary disputes.

02. Solution

Mapped multi-tier attendance rules (split shifts, grace periods, sandwich leaves, holiday overtime) into a structured FRD and automated the payout calculation engine using a SQL & Python rule engine.

03. System Logic

IF Punch_Out IN [00:01..04:00] -> Map to Prior_Shift_Date. Holiday_OT = (Worked_Mins - 480) * 2.0

04. QA Verified & Result

✓ QA Edge-Case Passed: Cross-midnight punch on public holiday logs 1 shift, not 2 absent days.

Impact: 3 days to under 30 minutes monthly payroll reconciliation (95%+ time saved) with zero recurring salary disputes.

SQL Python FRD Writing Jira QA
Production & BOM Module Case 02

ERP Production Module & Multi-Stage BOM Architecture

01. Problem

FMCG multi-stage manufacturing yield losses weren't tracked at the sub-batch level, leaving raw material wastage and QC rejects invisible until quarterly stock audits.

02. Solution

Designed a comprehensive Baserow MRP schema that enforces machine capacity limits, tracks multi-stage sub-batches, and logs stage-wise yield variances against standard BOM formulas.

03. System Logic

Yield_Loss_% = ((Std_BOM_Qty - (Good_Output + Scrap_Rec)) / Std_BOM_Qty) * 100

04. QA Verified & Result

✓ QA Edge-Case Passed: Blocks batch closure if sub-batch output exceeds machine capacity or variance > 5% without supervisor reason code.

Impact: 100% stage-wise BOM visibility across sub-batches, automatically flagging yield losses exceeding 5% variance.

Procurement & Logistics Case 03

Purchase-to-Pay (P2P) Module & 3PL Courier API Sync

04. QA Verified & Result

Impact: 100% PO-to-GRN match accuracy and real-time webhook tracking across all 3PL courier partners, cutting manual follow-ups to 0 hours/week.
